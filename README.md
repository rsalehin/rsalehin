## Selected Projects

### 🔭 [icm-magnetic-field-kb](https://github.com/rsalehin/icm-magnetic-field-kb)
Local hybrid RAG and knowledge graph over 1,000+ astrophysics papers.
Dense retrieval (SPECTER2) + BM25 with RRF fusion, DuckDB structured metadata, NetworkX citation graph, FastAPI backend, D3.js frontend, Chrome extension.
> `Python` `FAISS` `DuckDB` `NetworkX` `SPECTER2` `BGE-M3` `BM25` `FastAPI`

### 🌌 [DeepLense-GSoC-2026](https://github.com/rsalehin/DeepLense-GSoC-2026)
ML4SCI Google Summer of Code 2026 — three proposals for gravitational lens finding, unsupervised super-resolution of lensing images, and LSST data processing pipeline.
SO(2)-equivariant CNN for lens classification · CycleGAN-style unpaired SR · Butler/LSST pipeline simulation.
> `PyTorch` `Deep Learning` `Astronomy` `Computer Vision` `GSoC`

### 🛠 [repo2rag](https://github.com/rsalehin/repo2rag)
CLI tool for converting GitHub repositories and documentation sites into single Markdown files for RAG ingestion, with six enrichment passes including API index extraction and cross-reference tables.
> `Python` `CLI` `RAG` `Developer Tools` `LLM`

### 🔭 [project-kepler-elastic](https://github.com/rsalehin/project-kepler-elastic)
Exoplanet research assistant combining Elasticsearch hybrid search with Vertex AI/Gemini. Built for Google Cloud Hackathon.
> `Python` `Elasticsearch` `GCP` `Gemini` `FastAPI` `Hybrid Search`
